# Регистрация

## Требования

- Есть отдельная страница регистрации `/register`.
- Пользователь может зарегистрироваться с помощью email и пароля.
- Форма содержит подтверждение пароля.
- Успешная регистрация переводит на `/login`.
- При ошибке регистрации отображается сообщение.

## Пользовательские сценарии

### Успешная регистрация

- Пользователь открывает `/register`.
- Пользователь вводит email, пароль и подтверждение пароля.
- Пользователь нажимает Register.
- Пользователь создан, открывается `/login`.

### Email уже зарегистрирован

- Пользователь открывает `/register`.
- Пользователь вводит уже зарегистрированный email, пароль и подтверждение пароля.
- Пользователь нажимает Register.
- Пользователь видит сообщение об ошибке и остаётся на `/register`.
