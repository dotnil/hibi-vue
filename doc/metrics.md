# Выполнение привычек

## Требования

- Пользователь может отметить выполнение привычки за выбранный день.
- Пользователь может снять отметку выполнения привычки.
- Прогресс привычки пересчитывается после изменения отметки.

## Пользовательские сценарии

### Отметка выполнения

- Пользователь нажимает на день нужной привычки.
- День отображается выполненным.
- Прогресс привычки пересчитывается.

### Снятие отметки

- Пользователь нажимает на уже отмеченный день привычки.
- День отображается невыполненным.
- Прогресс привычки пересчитывается.
