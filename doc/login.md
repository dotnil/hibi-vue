# Вход

## Требования

- Есть отдельная страница входа `/login`.
- Пользователь может войти с помощью email и пароля.
- После успешного входа открывается главная страница.
- Авторизованный пользователь может выйти из приложения.

## Пользовательские сценарии

### Успешный вход

- Пользователь открывает `/login`.
- Пользователь вводит email и пароль.
- Пользователь нажимает Login.
- Открывается главная страница с привычками пользователя.

### Выход

- Пользователь открывает меню на главной странице.
- Пользователь нажимает Logout.
- Открывается `/login`.
