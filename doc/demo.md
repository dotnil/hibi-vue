# Демо-режим

## Требования

- Пользователь может пользоваться приложением без авторизации.
- В демо-режиме можно создавать, изменять и удалять привычки.
- В демо-режиме можно отмечать выполнение привычек.
- Изменения в демо-режиме не сохраняются на сервере.

## Пользовательские сценарии

### Работа с привычками

- Пользователь открывает главную страницу без авторизации.
- Пользователь создаёт, изменяет или удаляет привычку.
- Изменения отображаются в списке.

### Отметка выполнения

- Пользователь нажимает на день привычки.
- День отображается выполненным или невыполненным.
- Прогресс привычки обновляется.
