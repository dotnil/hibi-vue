# Привычки

## Требования

- Пользователь может создавать привычки.
- Пользователь может изменять название, цель и цвет привычки.
- Пользователь может удалять привычки.

## Пользовательские сценарии

### Создание привычки

- Пользователь открывает форму создания привычки.
- Пользователь вводит название, выбирает период, цель и цвет.
- Пользователь нажимает Create habit.
- Новая привычка появляется в списке.

### Редактирование привычки

- Пользователь открывает редактирование привычки.
- Пользователь изменяет название, цель или цвет.
- Пользователь нажимает Save changes.
- В списке отображаются изменения привычки.

### Удаление привычки

- Пользователь нажимает удаление привычки.
- Привычка исчезает из списка.
