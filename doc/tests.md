# Тесты

В проекте тесты пишутся по фиче, юнит тесты не используются. Фича проверяет работу приложения как срез через все системы. Мокаются только внешние вызовы.

Тестируется весь frontend: настоящие компоненты, маршрутизация и API-клиент. Подменяются HTTP-запросы к бекенду.

Vitest запускает тесты. Vue Test Utils монтирует приложение и позволяет взаимодействовать с DOM. jsdom предоставляет браузероподобное окружение без запуска браузера.

Внешние HTTP-запросы мокируются через `vi.stubGlobal`:

```js
vi.stubGlobal('fetch', vi.fn().mockResolvedValue(
  new Response(JSON.stringify(data), { status: 200 }),
))
```
